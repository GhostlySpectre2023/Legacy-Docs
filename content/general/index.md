# Welcome to Legacy Scripts

Official documentation for the FiveM resources made and sold by Legacy Scripts, the development team behind Legacy Roleplay NL.

## What is Legacy Scripts?

Legacy Scripts builds the resources that run on Legacy Roleplay NL and makes them available to other FiveM servers. Every resource is written with the same goals in mind:

- **Server-authoritative.** Prices, permissions, distances and items are checked on the server, not trusted from the client.
- **Framework-friendly.** Most resources detect Qbox, QBCore or ESX automatically and keep all framework-specific code in an open bridge file.
- **Editable where it matters.** Config files, locales and bridges stay open after Cfx.re Asset Escrow, so you can adapt them to your server.
- **Multilingual.** Most resources ship with several languages and fall back to English for missing texts.

## How to use these docs

Every product has the same set of pages, so you always know where to look:

1. **Overview** - what the resource does, its features, supported frameworks and dependencies.
2. **Installation** - step by step, including the `ensure` order, SQL and inventory items.
3. **Configuration** - a walk through the real config file with every option explained.
4. **API** - exports, events and commands you can use from your own scripts (only where they exist).
5. **FAQ** - the most common problems and how to fix them.
6. **Changelog** - the current version and what changed.
